# 核對入帳（銀行對帳）操作指南

> 目的：把永豐銀行的入帳明細一次匯入，系統自動對出「這筆錢是哪張單的」，
> 按一次確認就完成收款登記 —— 不用一筆筆手動記帳。

## 事前條件（一次性）

1. **銀行**：目前支援永豐銀行的「往來明細」CSV（UTF-8）。
2. **匯款備註要有案件編號**：自動配對靠的是入帳備註裡的編號
   （`L`/`S`/`P` + 數字，例：`P6142`、`S906`）。
   請客戶匯款時在備註填單號 —— 匯款訊息（收款訊息產生器）裡本來就會附單號，
   照著用即可。備註沒有編號的入帳，系統對不出來，需在畫面上手動指定。

## 每週操作三步驟（約 5 分鐘）

### 1. 下載銀行明細
永豐網銀 → 帳戶往來明細 → 匯出 CSV（選 UTF-8）。

### 2. 匯入系統
系統左側選單 → **核對入帳** → 把 CSV 拖進虛線框（或點「選擇檔案」）。

系統會自動：
- 過濾出「入帳」交易（出帳不處理）
- 從備註抓案件編號 → 對到應收帳款 → 再用金額對到分期（訂金／尾款／全額）
- 標信心度：**高**＝金額完全相符；**中**＝金額差 50 元內（可能扣了匯費）

### 3. 檢查後按確認
- 對好的項目看一眼（案件、金額、訂金/尾款），沒問題就按
  **「確認已配對項目」**
- 沒對到的：用該筆的下拉選單手動選案件，再確認
- 確定不是貨款的入帳（例如利息）：點忽略

按下確認後系統自動完成：
- 應收帳款登記收款（該期變「部分收款」或「已收款」）
- 入帳比應收少 ≤ 50 元 → 差額自動當匯費沖銷，該期直接結清
- 發票列表的收款狀態同步變化、逾期自動消失
- 寫入核對歷史（同一筆入帳不會重複登記）

## 常見問題

| 狀況 | 處理 |
|---|---|
| 客戶匯款沒填備註 | 畫面上手動選案件即可；長期解法是請客戶照匯款訊息填單號 |
| 一筆錢付兩張單 | 目前一筆入帳只能對一期；請分開對或到應收頁手動登記 |
| 金額差超過 50 元 | 會登記為部分收款，差額原因請人工確認後再處理 |
| 不小心確認錯 | 到應收帳款頁找該筆調整（核對紀錄保留稽核軌跡） |
