# 銀行對帳操作指南

> 目的：拿永豐銀行的往來明細，檢查「每筆入帳都已經記進應收帳款」、
> 「應收記的每筆匯款銀行都真的有收到」。**只核對、不寫入**。

收款仍然照平常：客人回報匯款時，在應收明細頁「記錄收款」並填末五碼。
這頁是事後抓漏用的——舊版「核對入帳」會把收款再寫一次進應收，會重複入帳，已移除。

## 怎麼用

1. 永豐網銀 → 帳戶往來明細 → 匯出 CSV（可以一個月一份，一次選好幾份）。
2. 系統 → **應收帳款** → 上方分頁 **銀行對帳** → 把 CSV 拖進虛線框（或點「選擇檔案」）。
   舊網址 `/bank-reconciliation` 會自動導到這裡。
3. 先看上面的問題類，✅ 與 ⚪ 預設收合。

## 結果怎麼分

| 類別 | 意思 | 要做什麼 |
|---|---|---|
| ❗ 銀行有入帳、系統沒記錄 | 末五碼、單號、金額都找不到對應收款 | 點「應收明細」補記，或確認是別的款項 |
| ❌ 系統有記、銀行沒看到 | 明細期間內記為匯款、收款帳戶是這份明細的帳戶（或沒填），銀行卻沒有 | 檢查是不是匯到別的帳戶、日期或金額記錯 |
| ⚠️ 金額不符 | 末五碼或單號對上了，金額差超過 $50 | 核對實收金額 |
| 🔍 可能是 | 沒有末五碼／單號，只有金額相同（差 $50 內）且日期差 5 天內的唯一一筆 | 人工確認，系統不會自動認定 |
| ✅ 一致 | 末五碼＋金額、或備註單號＋金額對上（差 $50 內記為手續費）；同末五碼幾筆加總等於一筆收款（14 天內）算「分筆入帳」 | 不用處理 |
| ⚪ 非訂單款 | 利息、大戶回饋、退款、自家帳戶互轉 | 不用處理 |

## 比對規則

- **末五碼**：取入帳備註裡 10～19 位數的匯款帳號末五碼，比對應收分期的「末五碼」欄；
  舊資料沒有這欄時，改看分期備註裡獨立的 5 位數（例「(18173) 囉」）。
- **自家帳戶**（匯款資訊頁的收款帳戶）的末五碼不當成客人末五碼，改用單號或金額比對，
  都對不上就歸「內部帳戶轉入」。
- **單號**：備註裡的 P／S／L＋數字（全形、中間有空白也認得），連到訂製訂單 → 同案件的應收。
- 每筆收款只會被一筆入帳（或一組分筆）對走。
- 支出不核對，只顯示筆數。
